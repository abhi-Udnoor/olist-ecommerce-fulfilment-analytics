# Project Data

This directory documents the datasets used in the project.

## Source

Olist Brazilian E-commerce Public Dataset.

## Local data organisation

- `raw/` – Original source CSV files.
- `processed/` – Cleaned and transformed datasets.

## Data management

Raw and processed data files are stored locally and are not committed to this public repository by default.

Refer to the dataset source and data preparation documentation before using the analytical scripts.
