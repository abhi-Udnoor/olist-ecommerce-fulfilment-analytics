# SQL Server

This directory contains the SQL Server scripts used throughout the project.

## Processing layers

- `00_setup/` – Database creation and configuration.
- `01_raw/` – Raw source table definitions and ingestion.
- `02_staging/` – Data cleaning and standardisation.
- `03_data_quality/` – Data validation and quality checks.
- `04_analytics/` – Analytical models and reusable views.
- `05_business_analysis/` – SQL queries answering business questions.

All scripts will use SQL Server (T-SQL).
