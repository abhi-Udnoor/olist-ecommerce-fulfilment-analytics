# Project Documentation

This directory contains the business and technical documentation for the Olist E-commerce Fulfilment Analytics project.

## Documents

| Document                         | Purpose                                                              |
-----------------------------------------------------------------------------------------------------------
| Business Requirements Document   | Defines the business problem, objectives and analytical requirements |
| Project Charter and Scope        | Establishes project boundaries, deliverables and timeline            |
| Stakeholder Requirements         | Documents stakeholder questions and expectations                     |
| KPI Dictionary                   | Defines business metrics, formulas and measurement rules             |
| Data Dictionary                  | Describes source tables, columns and data types                      |
| Data Quality Report              | Records data validation results and identified issues                |
| Architecture and Data Model      | Explains the analytical architecture and table relationships         |
| Assumptions and Limitations      | Documents assumptions and constraints                                |
| Decision Log                     | Tracks important project decisions and their rationale               |

Detailed documents will be added as the project progresses.
